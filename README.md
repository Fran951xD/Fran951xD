## Hola, soy Francisco

Estudio Ingeniería en Sistemas de Información en la UTN (Facultad Regional Córdoba, 3.er año). Soy desarrollador web full stack: hago aplicaciones con **Python (FastAPI)** y **JavaScript/TypeScript (Next.js)** sobre bases de datos SQL, que resuelven problemas concretos de acá: gastos compartidos, turnos, stock, oficios. Me interesa sobre todo integrar inteligencia artificial en productos para automatizar tareas y que el resultado sea confiable.

Busco mi primera experiencia profesional, remota y part-time.
